# Noyyal Rising — Environmental Data Analysis

Data-driven investigation into the impact of textile industry 
pollution on agriculture in Tamil Nadu's textile districts 
(Tiruppur, Erode, Coimbatore).

## Projects
1. Crop Yield Trend Analysis — Tiruppur vs Erode (2008-2020)
2. Air Quality Mapping — Tamil Nadu Industrial Districts
3. Air Pollution vs Crop Yield Correlation Analysis

## Tools
Python, Pandas, Matplotlib, Folium, SciPy

## Data Sources
- India Agriculture Crop Production (Kaggle)
- Tamil Nadu Air Quality Data — CPCB (Kaggle)

## Part of Noyyal Rising
A river justice campaign fighting textile effluent 
pollution in the Noyyal River basin.
